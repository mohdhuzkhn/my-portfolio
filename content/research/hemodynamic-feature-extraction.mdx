## Problem

Rupture-risk assessment for cerebral aneurysms traditionally depends on a specialist manually interpreting a computational fluid dynamics (CFD) simulation. That doesn't scale, and it isn't fully reproducible between readers.

## What this pipeline does

Blood flow through the aneurysm geometry is simulated, and a fixed set of hemodynamic features — wall shear stress, oscillatory shear index, and flow impingement — is extracted at the aneurysm surface. Those features feed a risk-scoring model rather than requiring a specialist to read the simulation directly.

## Where it stands today

The model performs comparably to specialist manual review on the held-out evaluation set. That is a meaningfully different claim than "ready for clinical use" — see Limitations above for exactly why, and Future Work for what needs to happen before that gap closes.
