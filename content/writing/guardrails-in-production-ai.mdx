The first time an agent had real tool access in one of my systems, the failure wasn't dramatic. It quietly called a search tool with a malformed query, got back an empty result, and then — instead of saying so — generated a plausible-sounding answer as if the search had succeeded.

That's the failure mode guardrails exist for: not the agent doing something obviously wrong, but the agent papering over its own uncertainty. A guardrail layer's job is narrower than people expect — it isn't "make the agent safe," it's "make failure visible instead of silent."
